AI 使用說明

使用什麼工具？

執行時使用 Ollama 提供本地 LLM 推論，預設模型為 llama3.2；Python 用標準函式庫向 /api/chat 送出請求。製作專案範例時亦使用 ChatGPT 協助產生程式、網頁文案與測試草稿。

AI 用在哪裡？

AI 分析客服來信，產生分類、案件優先度、摘要、建議回覆四個欄位。透過 API 的 format 傳入 JSON Schema，使用結構化輸出功能；Python 另外執行欄位與值驗證。

哪些地方需要自己修改或驗證？

已在 Windows PowerShell 執行 ollama run llama3.2、uv sync 與 uv run mail-triage --file examples/email.txt，證實模型能輸出四欄 JSON。觀察到配送查詢被誤判成退換貨後，修改分類提示詞以明確區隔兩者，並加入更多自動化測試。此修改由 ChatGPT 協助撰寫，後續模型實測準確率仍待驗證；參見「執行結果」。

隱私與限制

客服郵件可能含個資，請使用虛構或去識別化測試內容。模型可能分類錯誤或生成不實回覆，因此所有建議應由人工核對。使用本地 Ollama 不必將郵件交給雲端模型，且不需 API Key。
