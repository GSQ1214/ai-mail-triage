執行結果與改進

已完成的本機測試

使用 Windows PowerShell、Python 3.12.16、uv、Ollama 0.40.15 與 llama3.2，執行：

uv sync
uv run mail-triage --file examples/email.txt

程式確實回傳四欄 JSON，但第一次分類出現語義誤判：

{
  "category": "退換貨",
  "priority": "高",
  "summary": "請幫我確認配送狀態",
  "suggested_reply": "我們會儘快回覆至您，謝謝您的了解。"
}

以上文字來自使用者提供的 PowerShell 執行截圖之轉錄，並非本網站執行的 LLM；摘要與建議回覆保留了當時的實際措辭。

問題分析與修正

原始信件主要是詢問包裹運送進度，正確的人工標註應為「物流配送」，不應被分類成「退換貨」。因此已調整分類提示詞，明確區分配送查詢與退貨請求；也將 temperature 設為 0，以降低非必要的輸出變動。

調整後的模型準確率尚未進行多案例實測；temperature 0 不保證每次回覆完全一致。網站僅記錄已驗證事項，不宣稱已修正所有分類錯誤。

程式自動驗證

GitHub Actions 執行不依賴 Ollama 的單元測試，涵蓋 JSON Schema 欄位、合法分類、缺失欄位、非法型別、空白信件、非本機 API 位址與模擬 API 呼叫。正式推論仍需在自己的電腦上執行。
