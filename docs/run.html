怎麼執行

1. 準備環境

安裝 Python（或讓 uv 自動管理）、uv 與 Ollama，下載模型。

ollama pull llama3.2
ollama serve

如果 Ollama 已在背景執行，就不需要重複啟動 ollama serve。

2. 安裝專案

在下載或 clone 的 GitHub 專案根目錄執行：

uv sync

可選：複製 .env.example 為 .env 修改本機模型名稱。

3. 分類客服信件

uv run mail-triage --file examples/email.txt

# 直接輸入文字
uv run mail-triage --text "我收到的商品有瑕疵，想申請退貨。"

# 儲存結果
uv run mail-triage --file examples/email.txt --output result.json

4. 執行測試

uv run python -m unittest discover -s tests -v

本地測試不需啟動 Ollama；實際 AI 推論仍需模型可用。
